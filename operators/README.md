# 用户算子目录

把自定义算子 `.py` 文件放到本目录（或子目录）中，MineImage 启动时以及点击
**算子 → 刷新算子库（F5）** 后会自动扫描并显示在左侧算子库中。

* 也可以直接在算子库空白处 / 分类行右键「新建算子」：会自动生成带 `# TODO`
  注释占位的模板文件，并在列表里原地编辑文件名；右键用户算子可重命名、用
  **设置 → 算子目录 → 默认编辑器** 打开或删除。
* 子目录名会自动成为分类路径：一级目录 = 算子库中整行折叠的分类，更深层级 = 折叠分组。
  例如 `滤波/高级/双边.py` 会出现在“滤波”分类的“高级”折叠分组下。
* 也可以显式在 `OperatorSpec.category` 中写分类，显式值优先。
* 可以直接在算子库内拖动整理：把用户算子拖到分类 / 分组行会移动 `.py` 到对应
  子目录，并同步文件里的字面量 `category`；把用户分类行拖到另一个分类行会整体
  移动目录（含子分类），拖到列表空白处则提升为一级分类。拖动只在算子 / 分类所属
  的那个用户扫描根内生效；内置算子与没有用户目录的分类（含虚拟分组）不参与，
  `custom/` 保留目录不能作为分类拖动；文件移动不进入撤销栈。`category` 写成变量
  或函数调用时无法自动同步：单个算子会被拒绝并提示，分类移动时这类文件保留原
  分类并在提示里说明。
* 用户分类（磁盘上的真实目录）也可右键「重命名分类…」「删除分类…」：改名会同步
  目录内算子文件的字面量 `category` 前缀；删除会递归删除整个目录（含子分类与算子），
  无法恢复。非法名称、与同级重名只提示不修改；内置分类、虚拟分组与没有用户目录的
  分类行没有这两个动作，`custom/` 保留目录不支持；操作只在分类所属的用户扫描根内
  进行。
* 文件名以 `_` 开头会被跳过，因此 `_template.py` 不会被加载，可复制后改名使用。
* 需要更多扫描目录：**设置 → 首选项 → 算子目录**。
* 加载失败不会影响其它算子：**算子 → 查看加载日志** 查看原因。
* 算子组右键「保存为新算子…」生成的算子文件写入 `custom/` 子目录，并固定显示在
  算子库最顶部的「用户自定义算子」分类；它们的内部节点以 operator id 引用，不复制实现代码。
  依赖的算子暂时缺失时仍可加载，展开后的算子组内对应节点会显示「失效」，可右键替换。
* 保存算子文件后目录监视（默认开启）会自动刷新；即使关闭监视，下一次运行到
  该算子前也会检查文件变化并静默重载。

算子文件约定：模块级必须定义 `OPERATOR`（算子类或实例），详见
[docs/operator_guide.md](../docs/operator_guide.md) 和 `_template.py`。

> 注意：算子文件会在应用进程内执行 Python 代码，请只放可信来源的算子。
