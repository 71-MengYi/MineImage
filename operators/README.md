# 用户算子目录

把自定义算子 `.py` 文件放到本目录（或子目录）中，MineImage 启动时以及点击
**算子 → 刷新算子库（F5）** 后会自动扫描并显示在左侧算子库中。

* 子目录名会自动成为分类路径：一级目录 = 并排的一级分类按钮，更深层级 = 折叠分组。
  例如 `滤波/高级/双边.py` 会出现在“滤波”分类的“高级”折叠分组下。
* 也可以显式在 `OperatorSpec.category` 中写分类，显式值优先。
* 文件名以 `_` 开头会被跳过，因此 `_template.py` 不会被加载，可复制后改名使用。
* 需要更多扫描目录：**设置 → 首选项 → 算子目录**。
* 加载失败不会影响其它算子：**算子 → 查看加载日志** 查看原因。

算子文件约定：模块级必须定义 `OPERATOR`（算子类或实例），详见
[docs/operator_guide.md](../docs/operator_guide.md) 和 `_template.py`。

> 注意：算子文件会在应用进程内执行 Python 代码，请只放可信来源的算子。
